# 文件、附件与产物

## 生命周期

用稳定的上传操作 ID 和附件 ID 关联对象存储、解析任务与业务记录。沿用项目状态名，明确字节存储完成、解析完成和可供业务使用分别由哪个服务确认。

| 阶段 | 服务端契约 |
|---|---|
| 初始化与传输 | 认证并校验工作区，返回操作 ID、允许的类型和大小，以及上传位置与到期时间。支持分片或断点恢复时提供服务端已接受的进度。 |
| 确认上传 | 服务端核验登记对象的版本、存在性、大小和实际类型。按约定执行完整性校验，把可重试的确认绑定到同一上传操作。 |
| 后台处理 | 需要解析、转码或索引时持久化处理任务。返回待处理、就绪或明确失败，按产品契约拒绝或排队等待未就绪资源。 |
| 下载与预览 | 授权后按当前版本提供对象流或短期链接，指定内容类型、打开方式和到期策略。检查附件删除或授权撤销后不同访问方式的生效时间。 |

## 可重试操作与存储归属

- 传输中断后查询原上传操作，再按服务端确认的偏移或分片继续。解析失败时按契约重试同一份已上传对象及其版本。取消上传和取消解析各自有确认状态，清理任务依据操作归属和保留条件运行。
- 页面刷新可以复用原上传意图的键，或从服务端找回当前用户的未完成上传。确认阶段核对操作 ID 和已上传对象的版本，用工作区与上传操作 ID 的唯一约束或等价机制保护附件创建。需要可靠派发时，在同一事务确认会话并写入附件与解析分发记录。并发重发确认返回同一附件和已提交状态。
- 对象键由服务端分配并限制在预期租户或操作范围。对象直传使用范围受限的短期授权，完成回调重新校验归属与实际存储状态。用已确认的对象版本或不可变副本作为解析输入，防止确认之后内容又被覆盖。
- 类型和大小以服务端校验为准。根据项目风险约束解压、解析、扫描和隔离。用户文件名作为展示信息处理。服务端授权读取后，按内容类型和风险决定独立预览、隔离渲染或附件下载。[OWASP 文件上传指南](https://cheatsheetseries.owasp.org/cheatsheets/File_Upload_Cheat_Sheet.html)
- 报告等生成产物沿用任务与资源权限，用产物 ID、版本和生成任务关联已提交结果。授权期限只在所用访问方式确实支持的范围内保证。已签发的存储直链可能在过期前继续有效；需要即时撤销时，选择可按请求核权的下载入口或验证存储提供方确实支持的撤销机制。
- 删除文件后按业务要求处理附件引用、入库任务、索引和缓存。检索阶段如何阻止旧分片被继续引用，见 [Agent 上下文、记忆与检索](agent-context-and-retrieval.md)。

**验收证据**包括超限和错误类型被拒绝，刷新或断线后复用原操作，确认响应丢失后并发重发仍只创建一个附件和一条有效解析分发记录，解析失败后可定位阶段，跨租户、链接过期、权限撤销和取消竞速符合契约。
