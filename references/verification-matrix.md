# 后端验证矩阵

## 按问题选证据

检查受影响的实际入口和已有数据。先用最小场景区分原因，再选择验证层级。状态机和错误分类可用单元测试，数据库约束、代理转发、队列确认和进程恢复用能实际覆盖这些机制的集成检查。

| 场景 | 复现和验收证据 | 实现参考 |
|---|---|---|
| 入口失败、502/504 或 SSE 攒包 | 从对外入口记录代理与上游各自的状态、耗时和事件到达间隔。更换实例后按相同请求检查结果。 | [服务入口与流量治理](service-entry.md) |
| 扩容后延迟升高、缓存失效，或并发修改数据 | 比较连接等待、查询和锁时间及回源量。并发触发同一业务键，核对表中最终记录和允许的读一致性。 | [数据库、缓存与会话](data-and-cache.md) |
| 自动保存、身份切换、授权失效 | 双窗口同版本写入、成功后响应丢失、切账号或撤销权限后复用旧请求。核对最终版本、重试结果与是否发生越权读写。 | [API 状态与访问权限](api-state-and-access.md) |
| 文件上传确认或解析失败 | 中断传输、重复确认、让解析失败再重试。检查附件、对象版本和实际处理次数，验证链接过期和授权撤销。 | [文件、附件与产物](files-and-artifacts.md) |
| 超时、重试、隔离与积压 | 注入慢依赖与短暂不可用，确认总截止时间、尝试次数和其他流量未被占满。测试重复投递、补发或死信重放的业务效果。 | [容错与异步消息](resilience-and-messaging.md) |
| 任务恢复、SSE 补播和取消 | 重复提交、切换实例、断线、游标过期、Worker 结束、取消与完成同时发生。核对任务行、已提交事件、终态及外部副作用。 | [任务与流式响应](tasks-and-streaming.md) |
| 模型失败、无效输出或备用能力不足 | 用可控依赖返回限流、断流、结构错误和语义错误，核对路由、预算、输出状态和已执行动作。 | [模型接入与输出校验](model-integration.md) |
| Agent 工具审批、重启和检索越权 | 修改批准后的参数、撤销权限、丢弃外部回执或返回跨租户片段。分别核对工具调用、对账状态、实际上下文和引用。 | [Agent 工作流与工具执行](agent-workflows.md) · [Agent 上下文、记忆与检索](agent-context-and-retrieval.md) |
| 滚动发布和契约更新 | 同时运行新旧版本，带已有数据库状态和排队任务检查互操作、实例摘除和回退。 | [部署与服务演进](deployment-and-service-evolution.md) |

## 测试完成的定义

1. 说明实际入口、输入、初始状态与预期结果。修复任务保留可以复现的失败证据，区分候选原因和已确认原因。
2. 在可控场景对照修复后的响应、持久化状态与外部调用次数。涉及恢复或竞速时在明确的故障窗口触发，例如队列已消费但尚未确认。
3. 有跨端行为时，沿[前后端交互契约](frontend-backend-contracts.md)验证用户看到的状态和后台事实一致。涉及流量与性能时记录压测条件、采样范围及与基线比较的结果。
4. 优先使用仓库已有自动化和确定性替身。实际需要验证模型行为时，沿用项目已有的授权和评估入口。记录测试覆盖的情况与尚未验证的行为。

## 可复用的验收例子

**上传资料并生成报告。** 用户上传文件、解析就绪后只提交一次业务任务，再通过 SSE 查看进度。测试上传成功但确认响应丢失、提交后断线换实例、解析期间撤销文件权限三种情况。最终以附件记录、任务与事件序号、实际模型调用和所生成产物的权限为证据。
