# Agent 上下文、记忆与检索

## 先确认哪些数据允许进入上下文

- 明确系统配置、当前会话、已授权附件、检索片段和工具回执各自的来源。外部内容和模型建议用于推理，执行权限由服务端策略、当前身份和工具条件决定。
- 区分本轮上下文、会话历史、可恢复的运行状态、长期记忆和持久化产物。为确有长期需求的数据定义所有者、用途、保存期限和删除路径。项目需要时允许用户更正或移除会影响后续回答的记忆。
- 给会话历史、检索证据和工具结果分配上下文预算。记录被保留的输入版本和来源，在截断或摘要时保留关键约束、已批准动作和可核验引用。恢复从任务检查点与权威源读实际状态。[Agent 工作流与工具执行](agent-workflows.md)

## 入库、检索与引用

- 异步入库用资源 ID 和内容版本去重，分别记录存储、解析和索引状态。为失败、更新或索引尚未就绪定义可见状态和恢复路径。[文件、附件与产物](files-and-artifacts.md)
- 检索按用户、租户和资源权限限定可见集合。索引中的访问范围可能滞后，向模型返回片段以及向客户端开放原文前核对当前授权。查询缓存包含权限和数据版本的影响范围。
- 为返回的片段保留资源 ID、版本和可定位片段的引用标识。用户可点击的引用来自服务端实际检索及核权的结果，并按当前权限提供访问地址。正文中承载证据不足、索引滞后或部分来源不可用的真实结果。
- 数据更新或授权撤销后，明确何时停止检索、引用及展示旧版本。索引的异步更新可以滞后，承诺的访问限制应由实际读取路径执行。
- 撤销时若旧片段已进入运行中的模型上下文，按约定的生效时限标记受影响的上下文或运行结果失效。后续推送、重放、快照和衍生产物读取执行当前授权检查。对失效上下文生成的结果暂停交付，按业务选择结束运行或用获准的来源重新生成。停止供应商调用和控制应用向用户继续交付内容分别验证，之前已经交付的内容无法收回。

**验收证据**包括同一检索词按租户返回各自可见资源，文档撤销后滞后的索引内容不会进入新的上下文，入库重试不会重复产生当前版本的可见分片，引用能定位到承诺的版本和片段。用可控模型在已经拿到原片段、尚未输出时暂停运行，撤销权限后验证新的流事件、快照和产物按时限停止交付受限内容。
